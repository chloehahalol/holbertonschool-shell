# Shell, permissions

This project introduces how to manage file permissions in Linux.

## Scripts

- 0-iam_betty - Switches the current user to a different user.
- 1-who_am_i - Prints the username of the current user.
- 2-2-groups - Prints the groups the current user is a part of.
- 3-new_owner - Changes the owner of a file to the user betty.
- 4-empty - Creates an empty file called hello.
- 5-execute - Adds execute permission to the owner of a file.
- 6-permissions - Adds differing permissions to the owner, group owner and others.
- 7-everybody - Adds execution persmission to everybody.
- 8-James_Bond - Sets the permission of the files, only giving permissions to other users.
- 9-John_Doe - Sets the permission of the files based on a given mode.
- 10-mirror_permissions - Sets the mode of the file to the same as another file.
