# Shell IO Redirections and filters

This project is about learning how to manipulate command-line input and output, redirect data between commands and files, and process text.

## Commands Explored

```echo```
```cat```
```head```
```tail```
```find```
```wc```
```sort```
```uniq```
```grep```
```tr```
```rev```
```cut```
```passwd (5)```

## Scripts

- 0-hello_world - Prints a specified text.
- 1-confused_smiley - Prints a confused smiley face.
- 2-hellofile - Displays the contents of a specified file.
- 3-twofiles - Displays the contents of two files.
- 4-lastlines - Display the last lines of a file.
- 5-firstlines - Display the first ten lines of a file.
- 6-third_line - Displays the third line using a pipe to combine two commands.
- 7-file - Creates a script with a special-character filename and writes text into it. 
- 8-cwd_state - Store ls -la into another file.
- 9-duplicate_last_line - Duplicate the last line of the file.
- 10-no_more_js - Finds and deletes files with the js extension.
- 11-directories - Counts the number of directories and sub-directories in the current directory.
- 12-newest_files - Sorts all the files by newest to oldest and only shows the first 10.
- 13-unique - Taking a list of words, filtering and printing.
- 14-findthatword - Filters lines in a file with a pattern.
- 15-countthatword - Counts how many lines have a certain word in a file.
- 16-whatsnext - Finds lines with a word and then counts 3 lines after that.
- 17-hidethisword - Displays lines that DO NOT contain a word.
- 18-letteronly - Display all the lines starting with a letter.
- 19-AZ - Replace multiple characters.
- 20-hiago - Script that removes letters from the input.
- 21-reverse - Reverses the input.
- 22-users_and_homes - Displays users and directories and sorted, from a file.
