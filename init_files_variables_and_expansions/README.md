# Shell, init files, variables and expansions

This project focuses init files, managing variables, using aliases and working with different types of expansions.

## Scripts

- 0-alias - Creates an alias named ls that exeutes rm -f\*.
- 1-hello_you - Prints hello followed by the current Linux user's name.
- 2-path - Adds /action to the end of the PATH environment variable.
- 3-paths - Counts the number of non-empty directories listed in PATH.
- 4-global_variables - Lists the environment variables available to the shell using printenv.
- 5-local_variables - Lists shell variables and functions using set.
- 6-create_local_variable - Creates a local shell variable named BEST with the value School.
- 7-create_global_variable - Creates and exports an environment variable named BEST with the value School.
- 8-true_knowledge - Prints the result of adding 128 to the value of the environment variable TRUEKNOWLEDGE.
- 9-divide_and_rule - Divides the value of POWER by DIVIDE and prints the result.
- 10-love_and_exponent_breath - Calculates BREATH raised to the power of LOVE using Bash arithmetic expansion.
- 11-binary_to_decimal - Converts the binary number stored in BINARY into a decimal number.
- 12-combinations - Generates all possible two-letter lowercase combinations from aa to zz in alphabetical order, excluding oo.
- 13-print_float - Prints the number stored in NUM, formatted to two decimal places.
- 14-decimal_to_hexadecimal - Converts the decimal number stored in DECIMAL into lowercase hexadecimal.
