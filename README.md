# Holberton School Shell 🌸

This repository contains Bash scripting projects, completed as part of the Holberton curriculum.

It covers:
- Navigating the filesystem and managing files and directories.
- Understanding and modifying file permissions.
- Using input/output redirections and filters.
- Working with shell variables, expansions and aliases.
- Automating basic tasks using shell commands and scripts. 

## Contents 

There are four projects focused on Shell commands:

1. Shell, basics: cd, ls, pwd, less, file, ln, cp, mv, rm, mkdir, type, which, help, man

2. Shell, permissions: chmod, sudo, su, chown, chgrp, id, groups, whoami, adduser, useradd, addgroup

3.  Shell I/O Redirections and filtetrs: head, tail, find, wc, sort, uniq, grep, tr 

4. Shell, init files, variables and expansions: printenv, set, unset, export, alias, unalias, ., source, printf
